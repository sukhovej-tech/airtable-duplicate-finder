# Пошук дублів у таблиці  (Airtable)

Скрипт для Airtable Scripting — знаходить дублі серед записів у таблиці **"Співробітники"** та записує попередження у поле `DUPLICATE ALERT`. Якщо дублів немає — поле автоматично очищається.

## Як працює

### 1. Нормалізація даних перед порівнянням
Перед порівнянням скрипт нормалізує значення, щоб уникнути хибних розбіжностей через формат:

| Поле | Що нормалізується |
|------|-------------------|
| Телефон | Видаляє всі нецифрові символи, залишає останні 10 цифр (без коду +380) |
| Email | Приводить до нижнього регістру, обрізає пробіли |
| Ім'я | Нижній регістр, зайві пробіли, нормалізація апострофів (`'`, `ʼ`, `` ` `` → `'`) |
| Telegram | Пряме порівняння |

### 2. Пошук дублів
Для кожного запису скрипт порівнює його з усіма іншими. Збіг по **будь-якому** з полів вважається дублем:
- Пошта 1
- Телефон 1 (крос-порівняння з Телефон 2 іншого запису)
- Телефон 2 (крос-порівняння з Телефон 1 іншого запису)
- Telegram
- Ім'я

### 3. Запис результату
- **Є дублі** → у поле `DUPLICATE ALERT` записується:
  ```
  🚨 ДУБЛЬ З:
  ID 123: Іванов Іван — Email: ivan@example.com (Пошта 1)
  ID 456: Іванов Іван — Ім'я: Іванов Іван (Імʼя)
  ```
- **Немає дублів** → поле `DUPLICATE ALERT` очищається (`null`)

Записи оновлюються партіями по 50 (обмеження Airtable API).

### 4. Підсумкове повідомлення у консолі
- `✅ Готово! Знайдено дублів: N. Поле оновлено для всіх записів.`
- `✅ Готово! Дублів не знайдено. Всі попередження очищено.`

## Поля, які потрібні в таблиці

| Поле | Тип | Обов'язкове |
|------|-----|-------------|
| Співробітник | Text | Так |
| Пошта 1 | Email | Ні |
| Телефон 1 | Phone | Ні |
| Телефон 2 | Phone | Ні |
| Telegram | Text | Ні |
| ID | Number/Text | Ні (для зручного відображення) |
| DUPLICATE ALERT | Long text | Так (сюди записується результат) |

## Як запустити

1. Відкрити таблицю **"Співробітники"** в Airtable
2. Перейти у **Extensions → Scripting**
3. Вставити вміст `script.js`
4. Натиснути **Run**

## Зміни у версіях

### v1.1
- Поле `DUPLICATE ALERT` тепер **очищається автоматично** якщо дублів більше немає. Раніше старі попередження залишались після видалення дублів.
- Підсумкове повідомлення тепер показує реальний результат: кількість знайдених дублів або повідомлення про відсутність дублів.
