# PROJECT MEMORY — Пошук дублів в співробітниках

## Загальна інформація
- **Платформа:** Airtable Scripting (запускається вручну через Extensions → Scripting)
- **Таблиця:** "Співробітники"
- **Мова:** JavaScript (Airtable Script)
- **Репозиторій:** airtable-duplicate-finder (GitHub) — додати посилання після першого пушу

## Що робить скрипт
Знаходить дублі серед записів у таблиці Airtable за полями: Ім'я, Пошта 1, Телефон 1, Телефон 2, Telegram.
Записує попередження у поле `DUPLICATE ALERT`. Якщо дублів немає — поле очищається.

## Критичні технічні правила
- Порівняння відбувається після нормалізації: телефони → останні 10 цифр, email → lowercase, ім'я → lowercase + нормалізація апострофів
- Телефони порівнюються крос-полем: Телефон 1 одного запису vs Телефон 2 іншого і навпаки
- Airtable обмежує batch update до 50 записів — скрипт оновлює партіями
- `DUPLICATE ALERT: null` — очищає поле (важливо для видалення старих попереджень)
